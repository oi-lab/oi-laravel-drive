# Getting Started

OI Laravel Drive gives an entity of your application — a Team, an Organization, a Project — a **drive**: a tree of folders and files.

- Folders and files are the models of [oi-laravel-attachments](https://github.com/oi-lab/oi-laravel-attachments).
- Every folder and file has an **owner** (a user) and a **date of creation**, both settable.
- A file can be filed in **several folders**; filed in none, it is at the **root**.
- Deletions go to a **trash**, restorable.
- A JSON API, MCP tools for AI assistants and events come with it.
